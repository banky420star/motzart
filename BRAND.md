# Mozart Brand

**Mozart**  
**Autonomous Software Intelligence**

The product should feel like a living software organism, not a generic AI dashboard.

## Visual rules

- Start sparse. The core is born before the network.
- Structure is earned by real work. Never draw fake mature branches at project start.
- Movement is biological: membrane tubes, swelling nodes, peristaltic transfer, budding and absorption.
- Use restrained light on a near-black/navy surface.
- Primary palette: ink `#0f2747`, teal `#2ec4b6`, aqua `#8ee3d7`, coral `#ff8e73`, peach `#ffd6b6`.
- Motion communicates runtime state. It must never fabricate work.
